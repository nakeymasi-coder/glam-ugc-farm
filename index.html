Glam UGC Farm

One dashboard for your video intake, your locked characters and your run queue. Pick an agent on its own, use a solo form on its own, or run the full farm from the Video Intake Form.

Please read: this dashboard is your intake, vault and queue control panel. Submitting a form here does not by itself browse Pinterest, generate images or create videos. Those steps happen in chat, after you use Run in Chat. Nothing is ever posted automatically.

How the farm works

The farm takes a run from a Pinterest outfit to a finished 9:16 video, and brings the video back to you in chat for approval. You stay in control the whole way. The dashboard holds everything in one place: the Video Intake Form, solo forms for all 5 agents, the Character Vault for locked characters, and the Queue for runs.

The 5 agents, in order

1. Pinterest Scout

Finds outfits and products on Pinterest for your mode and topic, especially products available on Amazon with an affiliate link.

2. Image Agent

Creates the person and avatar images, the character references, the outfit reference and the outfit reference sheet. Ultra realistic, PNG, 9:16.

3. Story Agent

Writes the hook, the shots and the script, and labels every scene with your Product Presentation choice.

4. Muse Video Agent

Makes the video in Muse with its built-in video tool, using the locked headshot and the outfit reference sheet in every scene so the character stays the same. Returns it in chat for approval. It never posts it.

5. Caption Agent

Writes the TikTok caption, the on-screen hook and the hashtags. No price, discount or sale claim unless a live price was actually verified.

The Product Presentation rule

Every run picks one single choice, right after mode: Wearing the product or Holding the product. Never both in the same shot. A wearing run ends every prompt with: Wearing the product, not holding it. A holding run ends every prompt with: Holding the product, not wearing it. If a video needs both, holding comes first and wearing comes later, in separate scenes.

How Run in Chat works

Every run in the Queue has a Run in Chat button. Pressing it sets that run to working and opens its Run in Chat card, with the locked character, both slot photos, the voice, the mode, the Product Presentation choice and its exact prompt sentence, the topic, the length and the product details. The card has a Copy prompt button. You paste that prompt into a new chat, and that is what runs the farm. There is no scheduled pickup.

The workflow, step by step

  1. Pick the outfit on Pinterest. Choose the Pinterest outfit with an Amazon affiliate link. Copy its picture. Pinterest is searched from guest view, no sign in needed.
  2. Lock the outfit in chat first. Using the locked character reference photos, put that character in that exact outfit in chat, before any video is made. Check it for face match and outfit match.
  3. Make the outfit reference sheet in chat. From that approved outfit photo, create one single 9:16 reference sheet with front, profile and three quarter shots of her in that outfit, all on the same photo. Save it as PNG.
  4. Bring both references into Muse. Reference One is her headshot. Reference Two is that chat made outfit reference sheet. Never make a scene without both references.
  5. Create scenes in Muse from that headshot plus sheet lock, in script order, 9:16.
  6. Export and return the video in chat for approval. Do not post, publish or share it.

Muse video, same character every time

Videos are made in Muse (muse.ai) with its built-in video tool, right in chat. Every scene generation uses both locked references. Reference One is the headshot. Reference Two is the chat made outfit reference sheet. Never run a scene without both. No character bible is needed. The reference photos are the lock. Do not paste a bible into the scene prompts.

Every scene prompt uses this shape, and nothing else about her:

Use the reference images and keep the character perfectly consistent. [Scene action only.] [Spoken line, if any.] Wearing the product, not holding it.

Never describe her in the prompt. No face, hair, skin, body or outfit description. Describing her overrides the references and creates a different girl. The last line swaps to the holding version when that is the run choice.

Standing rules

  • Image format: every image created for the farm is PNG, not webp. That covers character images, outfit references and outfit reference sheets. Your own uploaded Vault photos stay as you saved them, JPG or PNG. WebP uploads are not accepted here.
  • Characters: ultra realistic, with real skin texture and real hair texture. Within one video, identity, clothing, location and lighting stay frozen from the uploaded reference photos.
  • Where videos are made: farm videos are made in Muse, with Muse's built-in video tool, in chat. No outside video app is used for farm runs.
  • Video allowance: Muse's video tool works on a daily allowance that refills on its own with time. There are no credits to buy, and a run never pauses for credits.
  • Queue status buttons only change the label to queued, working or done. They do not run Pinterest, image generation or video creation.

Character Vault

One record per locked character. Character A is reused as Character A, Character B as Character B, and so on. Every locked character needs both slots:

  • Slot 1, headshot: one photo, 9:16.
  • Slot 2, body reference sheet: one single 9:16 photo, not separate photos, with front, side view, profile and three quarter shots all on that same photo.

You can upload a character you already have outside the dashboard. Headshot goes in Slot 1, the single 9:16 body reference sheet goes in Slot 2. Uploads are accepted as JPG or PNG, as you saved them. WebP is not accepted. A character is not locked until both slots are filled.

The next letter is assigned for you, A, B, C and so on. Add the two slot photos on the character card after you add her.

Solo Agent Forms

Use one agent on its own, without a full run. Fill in the form and it builds a clean, ready to copy prompt for that agent job. You can copy the prompt, or add the job to the Queue.

Queue

Full farm runs and solo jobs together, newest first. Status is manual: queued, working or done. Changing status does not execute anything. Real execution starts from Run in Chat, and videos are made in Muse.
